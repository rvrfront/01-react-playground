# Playground

Proyecto de ejemplo basado en React para practicar componentes básicos.

## Funcionalidades
- Contador con incremento y decremento
- Interfaz simple con botones y visualización en pantalla

## Tecnologías utilizadas
- React 19.3.1
- TypeScript 6.0.3
- Vite 8.3.6
- ESLint para validación de código
- TypeScript ESLint para análisis estático

## Requisitos previos
- Node.js (versión 18+)
- npm (vendrá incluido con Node.js)

## Instalación
1. Clona el repositorio
2. Ejecuta `npm install` para instalar dependencias

## Scripts disponibles
- `npm run dev`: Inicia el servidor de desarrollo con Vite
- `npm run build`: Compila el proyecto para producción
- `npm run lint`: Ejecuta análisis de código
- `npm run preview`: Muestra la versión compilada

## Ejecución
Para desarrollar:
```bash
npm run dev
```

El proyecto estará disponible en http://localhost:5173
